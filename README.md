# NHL '94 Roster Tool

NHL '94 Genesis ROM Editor. This tool allows users to export a ROM to XLSX, make changes, and import it back into a .bin file to create a new custom ROM. 

## Web App

**[Launch Roster Tool](https://indi-sd.github.io/NHL-94-Roster-Tool/)**

## Desktop App

A standalone Windows and Mac app with the same functionality, built with Python and distributed as a single executable.
Download the latest version from [Releases](https://github.com/iNDi-SD/NHL-94-Roster-Tool/releases).
