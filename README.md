# NHL '94 Roster Tool

Read and edit player and team data inside NHL '94 Genesis ROMs. Export a ROM to XLSX, make changes, and import it back to a modified ROM. All processing runs in your browser — no files are uploaded.

## Web App

**[Launch Roster Tool](https://indi-sd.github.io/NHL-94-Roster-Tool/)**

- [User Guide](https://indi-sd.github.io/NHL-94-Roster-Tool/user-guide.html) — how to export, edit, and import roster data
- [Developer Reference](https://indi-sd.github.io/NHL-94-Roster-Tool/dev-reference.html) — ROM binary structure and implementation details

## Desktop App

A standalone Windows and Mac app with the same functionality, built with Python and distributed as a single executable.

Download the latest version from [Releases](https://github.com/iNDi-SD/NHL-94-Roster-Tool/releases).
