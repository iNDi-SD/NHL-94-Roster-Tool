Edit your roster.
No setup required.

This tool lets you pull player and team data out of a NHL '94 Genesis ROM into a spreadsheet, edit it, and write it back in. Everything runs in your browser.

✓ Before you start

What you need

Required

  • A NHL '94 Genesis ROM file (.bin)
  • A spreadsheet app - Excel, Google Sheets, or LibreOffice

Not required

  • An account or login
  • Any software install
  • An internet connection after the page loads

Your files stay on your computer. No data is sent anywhere. The ROM and spreadsheet are processed entirely inside your browser tab.

1 Step one

Set the 30 or 32 team toggle

NHL '94 ROMs come in two versions - 30 team or 32 team. You need to tell the tool which one you're working with before doing anything else.

30 Teams 32 Teams

Not sure which version you have? Load your ROM on the Export card and try exporting. If the team count is wrong, you'll see an error that tells you exactly what to switch to.

2 Step two

Export - Player/Team Data

This reads all team and player data out of your ROM and saves it as an .xlsx file you can open in any spreadsheet application.

1
Upload your ROM
Place or browse for your ROM file .bin of choice.
2
Click "Export ROM Data"
An export of all ROM player and team data will be generated for download.
3 Step three

Update Team/Player Data

The ROM export contains two sheets, Team Data and Player Data. Update the values you want to change, save the file. See the rules below.

!
Important Rules
No Blank Rows
All data must be one continuous block with no blank rows.
Consistent Team Order
The abbreviations in Team Data and Player Data must be in the same order.
Team Count
Both sheets must have exactly 30 or 32 teams to match your toggle setting. Adding or removing teams is not supported.
Player Count
Each team must have 1-4 goalies, 1-15 forwards, and 1-15 defense. Maximum 26 players total per team.

? Common Issues
→
Wrong team count
Your toggle doesn't match your ROM. Switch it to match the error message and try again.
→
Blank row in data
Delete the empty row the error identifies and re-upload.
→
Abv mismatch between sheets
Team Data and Player Data abbreviations must match exactly and be in the same order.
→
Name too long
First + last name combined must be 20 characters or under. Abbreviate the first name if needed.
→
Goalie has non-zero Chk, StH, or ShA
Set Chk, StH, and ShA to 0 for all goalie rows.
→
Wrong position order
Rows within each team must be ordered: goalies first, then forwards, then defense.
→
Value out of range
A stat is outside its allowed range. The error identifies the row and column - fix the value and re-upload.
→
Missing sheet
Both "Team Data" and "Player Data" sheet tabs must exist. Don't rename or delete either tab.
★ Tips
★
Export first, always
Always start by exporting from your ROM. Don't try to build a spreadsheet from scratch - the export gives you the correctly formatted file with all the right columns and structure in place.
★
The Ovr column is display-only
The Ovr column in Player Data is calculated from the player's stats and exported for reference. Changing it has no effect on the ROM - the actual player stats are what matter.
★
You can import without changing team names
If you only want to edit player stats or team ratings, you can delete the Team City, Team Name, and Arena columns from Team Data before importing. The tool will only update ratings and leave the original names in the ROM untouched.
★
Only one card active at a time
Loading a file on the Export card resets the Import card, and vice versa. This is intentional - the two operations are separate workflows and can't run at the same time.
★
Test in your emulator after every change
Load the modified ROM in your emulator and check the team and player screens before assuming everything worked. If something looks wrong, compare your spreadsheet against the original export to spot differences.
