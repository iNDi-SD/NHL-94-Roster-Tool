NHL '94 Online

Getting Started

Everything you need to install RetroArch and play online.

System requirements
  • Windows 7–11 (64-bit)
  • Mac with Metal (2015 or later)
  • USB or Bluetooth gamepad
Netplay requirements
  • Wired internet strongly recommended
  • Wi-Fi and satellite will not work well
  • Discord for opponent coordination

Install & configure RetroArch

1
Download RetroArch 1.17
Get the Windows 64-bit package and extract it somewhere accessible — the Desktop works fine.
2
Load the core
Launch RetroArch → Load Core → Genesis Plus GX (Genesis) or Snes9x (SNES).
3
Set your username
Settings → User → set it to your NHL94 Online username. Avoid special characters.
4
Load your ROM
Load Content → navigate to your ROMs folder → select your NHL '94 ROM.
5
Connect a controller
Most USB/Bluetooth gamepads configure automatically. Wired is strongly recommended for reduced input lag.
6
Start a netplay session
Press N in-game to toggle hosting. Use Tab to chat. Your opponent connects via the RetroArch lobby system.
⚠ No audio on Windows? Download directx_Jun2010_redist.exe from Microsoft and install it.
ℹ Upgrading? Copy only your ROMs folder from the old installation — do not copy retroarch.cfg as it may have incompatible network settings.
1
Download RetroArch 1.17 (Mac Metal)
Mount the DMG, drag RetroArch to Applications, then launch it.
2
Copy the config file
Copy retroarch.cfg to ~/Library/Application Support/RetroArch/config
3
Add cores and ROMs
Transfer cores and ROMs folders to Documents/RetroArch
4
Update core info files
RetroArch → Online Updater → Update Core Info Files.
5
M-series Mac only
Right-click RetroArch → Get Info → enable Rosetta mode before first launch.
6
Load core and ROM
Load Core → Genesis Plus GX or Snes9x. Then Load Content → your ROM file.
